# Contributing

## Adding a Mod

1. Fork the repository.
2. Create `mods/<your-id>/`. The folder name must match `id` in `mod.json`. Use lowercase letters, digits and dashes.
3. Pick a renderer and follow [MODS.md](docs/MODS.md). Start from a working example:
   - `mods/annie` (SVG)
   - `mods/pixel-byte` (PNG layers)
   - `mods/vrm-sample` (VRM: Blocky, generated by `scripts/make-sample-vrm.cjs`)
4. Check it locally:

   ```sh
   npm ci
   node scripts/check-mods.cjs mods/<your-id>   # fast: manifest, assets, file types, size
   npm start                                    # see it on the desktop; ⌘⇧S lists every Mod
   ```

5. Open a pull request with one Mod per PR. Include a screenshot of the character, ideally in each skin.

### What the PR check enforces

The `mods` workflow runs `scripts/check-mods.cjs` on every Mod your PR touches. A Mod fails if:

- `mod.json` breaks the schema or has unknown fields;
- an asset is missing, is the wrong type or is too large (PNG/WebP 4 MB each, VRM 40 MB, whole folder 60 MB);
- SVG markup contains anything outside the allowlist (scripts, links, event handlers, external URLs, inline styles, unknown classes);
- a VRM model loads external files or its licence does not allow redistribution;
- `license` is not an open licence: CC0, CC BY, CC BY-SA, MIT, Apache-2.0, or the VRM Public License with redistribution allowed;
- `license` contains terms such as "private", "prototype only", "fan", "non-commercial" or "not for public distribution";
- the Mod names no `author` (or `source`);
- the folder ships files other than `.json`, `.png`, `.webp`, `.vrm`, `.md`, `.txt`, or contains links or subfolders.

The full desktop CI also renders one Mod of each renderer in a real window.

### Artwork and licensing

Every character bundled in this repository must be **original, or openly licensed**. Anyone who clones the repository receives it.

- Contribute only artwork you made, or artwork under an open licence that allows redistribution and changes. Put the licence in `license` and the creator in `author`. If the artwork is not yours, link where it came from in `source`.
- Do **not** contribute third-party characters as bundled Mods. That covers VTubers, anime, manga, film and game characters, brand mascots, and fan art or "inspired by" outfits of any of them, whatever their licence says about personal use. Users get those characters themselves through the in-app avatar store, VRoid Hub, Booth or the official site, under their own licences, and the app keeps them on that user's Mac.
- No portraits of real people without their consent.
- Third-party code or models that the app downloads at run time go in [THIRD_PARTY.md](THIRD_PARTY.md) with their licence.
- Personas are prompts the AI follows. Keep them friendly, and do not tell the model to ignore the user or the app's rules.

## Code changes

Run `npm run check` (unit tests and the offline smoke set) before opening a PR. Keep each change focused, and add or update a test with it.
