# 跨 Agent 角色與 Skin 市集：兩週 PoC

日期：2026-10-02。方向已由使用者確認；以下範圍、時間表與數字是執行建議，並非已觀測成果。

產品承諾：**你的 AI，你選角色。換 Agent，不換夥伴。**

## 第一個可執行里程碑（2026-10-02）

已實作 Electron 桌面角色＋本機網頁控制台、三種 SVG rig（Miso、Byte，另一個品牌示範角色已移除）、六套 Skin、三種個性、共享 Runtime 和宣告式 manifest 驗證。網頁換角色／Skin／個性同步桌面，換外觀保留進行中的活動；原生 smoke 操作已驗證。Codex 改用真正 App Server，已收到真實工作／完成事件並以 Miso 完成角色對話。本輪 App Server 為 chat-only，尚未交付示範專案編程或批准 UI。

Claude 的聊天、觀察 hooks installer、bridge、專案連接入口已實作；單元測試通過，但真實 Claude 請求遭帳號週額度阻擋，正常對話完成 hooks 的 live 驗證尚未完成。LM Studio 本機 API 與配置保留，接口以 mock 測過；本機服務目前未連通，未驗證真實本機模型推理。詳見 [README.md](../README.md)。此里程碑不是整個兩週 PoC 或付費市集已完成。

## 要回答的問題

正在用 Claude Code 或 Codex 工作的人，是否願意讓一個角色常駐桌面，觀看它對真實工作做出反應，並為外觀或完整角色包付費？跨 Agent 是待驗證的購買理由，而非預設成立的優勢。

首批用戶：已安裝並登入 Claude Code／Codex、每天使用 AI 工作的 macOS 用戶。先招募 10 人，盡量包含 4 位兩家都用的人；招募樣本不限定 crypto。一位工程師負責實作，使用者負責角色方向、招募與訪談。平台先用獨立暫名 Agent Wardrobe，暫名不代表商標已確認。內建角色一律原創或採開放授權，預設角色是 Annie。

## 一次完整體驗

1. 開啟桌面 App，偵測已安裝的 Agent；未安裝／未登入者看到明確設定指引。PoC 一鍵體驗適用於已具備環境的使用者。
2. 選 Annie、原創貓或原創小機器人，預覽動作後套用。
3. 選 Claude、Codex 或 LM Studio：Claude 連到指定專案內已安裝觀察 hooks 的 CLI；Codex 從 App Server 啟動受管理工作階段；LM Studio 連本機 API，先支援聊天。兩個工作 Agent 各跑一項真實小任務，本機模型跑一次真實對話。
4. 角色依事件呈現等待、工作、等待使用者批准、完成或出錯；沒有事件資料時顯示未知／離線，不用演出假裝工作。
5. 任務中可換外觀；工作階段與任務不重啟。可切換陪伴、吐槽、教練個性，改變角色評論。
6. 切換 Agent，保留角色、個性和外觀。切換預設開啟該 Agent 的獨立工作階段，不自動傳遞另一家的私密對話或承諾接續未完成任務。
7. 開啟內建市集，預覽、安裝一套本機示範 Skin；對明確標註的測試價格表示購買意向，沒有真實扣款。

## 必做範圍

| 部分 | 兩週交付 | 驗收 |
|---|---|---|
| 桌面角色 | macOS 透明、置頂、可拖曳視窗，選配系統語音 | 日常工作能操作；可隱藏、靜音、退出 |
| Agent 接入 | Claude Code、Codex 受管理的工作階段；共用事件介面 | 各自跑過真實任務；成功、失敗、批准事件有記錄 |
| 本機模型 | 保留 LM Studio 作為第三個引擎，設定本機 URL 與模型 | 取得模型清單、完成真實聊天；斷線／無模型有提示；與兩家共用 Skin／個性 |
| 角色與 Skin | Annie、貓、機器人；六個視覺狀態 | 同一任務中換 Skin 不丟失進度；兩家都可使用 |
| 個性 | 陪伴、吐槽、教練三種 | 僅角色評論改變；執行權限與原任務不被換個性改寫 |
| 市集 | 3 個示範商品、動作預覽、安裝、套用、價格意向 | 區分已安裝／套用中；測試商品與價格明確標示 |
| 語言 | 依電腦偏好設定預設；對話依使用者语言 | 繁中、簡中、英文、日文介面；其他介面先回退英文；AI 跟隨輸入語言 |
| 試用紀錄 | 本機最小事件記錄與使用者主動匯出 | 記錄時間、切換、錯誤、試用天數；不收集提示內容／程式碼 |

六個視覺狀態：idle、working、waiting_for_approval、speaking、success、error。thinking 只有在提供者確實提供相應事件時才細分；不顯示或推測內部思考內容。連線狀態與任務狀態分開，idle 不代表已完成。

語音先用 macOS 現有聲音，依語言挑選可用聲音；缺少對應語音時保留文字且可靜音。暫不做語音辨識、聲音克隆或精確嘴型。

## 技術接法與邊界

沿用已起步的 Electron 桌面程式。UI 不直接持有憑證；主程序管理 Agent 進程、事件、設定與套件安裝。

- Codex：優先評估 App Server 的受管理工作階段與事件。現有 CLI 單次聊天已測到成功回覆；尚未驗證工作事件、批准流程或完成桌面打包。
- Claude Code：依使用者指定，以 hooks 作為角色狀態主要來源。參考 firstmate 專案級設定的合併／移除方式，安裝自有的輕量觀察 hooks，不搬入阻擋或喚醒工作流。需要聊天文字串流時另用 CLI streaming JSON。既有專案 CLI 在安裝 hooks 並驗證後可連接，不宣稱能接入沒有 hooks 的官方視窗。
- LM Studio：依使用者最新指示保留本機 OpenAI-compatible API；用 `/models` 和 `/chat/completions`。PoC 先保留目前本機聊天路徑，動畫由 App 的請求、回覆、語音和錯誤驅動；本機模型不自帶 Claude／Codex 的工作或批准事件，不在此階段另建通用工具執行 Agent。
- 兩種 adapter 正規化為 `sessionId, provider, eventId, timestamp, kind, payload`。事件來源、重連、重複事件、終止狀態可追溯。
- PoC 只支援由 App 啟動的工作階段；不宣稱能替換官方 App 內角色、監控所有既有視窗，或跨家無縫遷移執行中任務。
- 角色反應優先用本機動畫與簡短文案映射，不為每個工具事件多呼叫模型。個性評論必要時才調用 AI；不更動任務執行指令。
- 每個請求仍受既有帳號、登入方式、方案與使用限制影響。商業公開分發前另驗證各家整合與授權條件；本次測試不將個人 CLI 登入等同於可轉售推理服務。

使用者提供 `/Users/benjamin/Desktop/firstmate-workflow` 作為接入參考並指定 Claude hooks／Codex App Server，之後確認保留 LM Studio。已唯讀檢視該 checkout 的 installer、supervision 文件、兩家 adapter 與 T-150 規格；證據界線與工作項見 [INTEGRATION-NOTES.md](INTEGRATION-NOTES.md)。

## Mod 格式

`Mod = 角色身份 + 預設 Skin + 可選個性 + 語音偏好`。Skin 與個性可獨立替換；引擎切換不改變已選 Mod。

套件包含版本化 manifest、宣告式視覺資產、六個狀態映射、顯示名稱、作者、授權說明與靜態個性文字。PoC 用本機白名單套件，安裝採暫存驗證後原子套用，失敗回復上一套。拒絕可執行腳本、任意 HTML、外部資產 URL、路徑穿越及過大檔案。個性文字不能增加 Agent 權限。先選單一宣告式渲染格式，不同時支援 Live2D、3D 和多種插件框架。

## 測試與驗收

工程驗收：每家至少一次成功、失敗與批准情境；事件不能錯配到另一工作階段；中途換 Skin 保持任務；断線不顯示假完成；退出清理自己啟動的進程；未登入／超額有可理解提示；設定持久化；安裝失敗恢復舊 Skin；不執行套件程式碼。批准流程以示範專案測試，不以繞過批准達成一鍵。

產品門檻是方向性建議，10 人的小樣本不代表市場已成立：

| 指標 | 建議繼續門檻 | 分母與定義 |
|---|---|---|
| 啟用 | 至少 8 人 | 10 位受邀且開始安裝的人；在 5 分鐘內完成套用角色與啟動已登入 Agent |
| 再次使用 | 至少 5 人 | 同一批 10 人；三天內至少兩個不同日期主動啟動，排除訪談要求啟動 |
| 換 Skin | 至少 4 人 | 同一批 10 人；離開引導後主動安裝並套用第二套 |
| 跨 Agent 價值 | 至少 2 人 | 至少 4 位原本兩家都用的人；自行切引擎並保留同一角色，而非只為完成測試 |
| 價格意向 | 至少 3 人 | 同一批 10 人；對某個具體 Skin 在 USD 3 或 5 的測試價選擇「願意購買」，並能說明理由；不當作營收 |

USD 3／5 為測試假設，不是競品價格或正式定價。樣本不足時報原始人數與原因，不把比例外推。

若安裝及事件已穩定，但少於 3 人自發回訪、大家主要關閉角色：先重新評估常駐價值。若角色受歡迎但跨引擎切換沒人用：可保留角色產品，暫緩「跨 Agent」作為核心賣點。若多人回訪但不想付費：先研究更有吸引力的 Skin 與購買場合，不直接建完整交易平台。

## 成本、交付與後續

先用現有電腦、既有 Agent 帳號、系統語音、本機目錄與靜態資產，不必採購 Live2D 授權、伺服器或付費配音。開發與試用消耗的模型額度仍存在，不能保證額外成本為零。先提供本機試用包；公開發布所需的簽章／公證與服務成本另計。

交付包含 macOS 試用包、可重現啟動方式、兩個 adapter、角色包格式與示例、最小市集、90 秒主流程展示，以及匿名化試用結果。目前只有部分程式、示範角色素材、初版 manifest 和一次 Codex 聊天成功，不把計畫寫成已完成。

後續再做創作者上傳、商品審核、授權管理、付款、退款、分潤、雲端同步、Windows 和更多 Agent。第三方角色不隨附、不上架，只讓使用者自行下載；先用原創角色測試付費意向。crypto 打賞、實盤交易與硬體不在此 PoC。
