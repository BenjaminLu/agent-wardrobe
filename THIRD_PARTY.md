# Third-party software, models and services

Agent Wardrobe includes the open-source code listed below. It also downloads some models and engines at run time, and only when the user asks. Downloaded items are **not** in this repository or the app bundle. Each one stays under its own licence, which the user accepts by downloading it.

The npm licences below come from each package's `package.json` and `LICENSE` in `node_modules`. The bundled licence texts are in `vendor/*-LICENSE`.

## Characters and artwork

Every bundled character (`mods/annie`, `mods/miso`, `mods/byte`, `mods/pixel-byte`) and the app icon (`build/`) is an original of this project, under the repository licence. Blocky (`mods/vrm-sample/sample.vrm`) is generated by `scripts/make-sample-vrm.cjs` and dedicated to the public domain under CC0 1.0.

Third-party characters (VTubers, anime and game characters, VRoid Hub and Booth models, Live2D samples) are never bundled. The avatar store shows each one's terms, and the user downloads it under those terms.

`library-thumbs/` holds thumbnails of pixiv's CC0 VRoid sample models only. See `library-thumbs/README.md`.

## Before you distribute this app

- **Live2D:** apps that use the Cubism SDK (this app's Live2D renderer does) may need a **Cubism SDK Release License** from Live2D. Live2D waives it for individuals and small businesses (annual revenue under 10 million JPY); larger publishers must contract with Live2D. See <https://www.live2d.com/en/sdk/license/>.
- **SenseVoice** (FunASR Model License) allows commercial use, but the model's source must be credited.
- **VOICEVOX** voice characters each have their own terms, often with conditions on commercial use, and each needs its credit line.
