CLI 使用既有登入與方案額度。聊天送往所選服務；本機模式送至你的電腦。

操作使用所選大腦。Claude 接官方工具；Codex／LM Studio 使用 App 瀏覽器與原生電腦工具。LM Studio 請載入支援 tools 的模型；電腦操作另需支援影像。

語音・聲音

使用 Edge 瀏覽器「大聲朗讀」的微軟線上語音：免費、免帳號，但要連網，說的文字會送到微軟。這是非官方介面，微軟改版時可能暫時無法使用，那時請先換成本機語音。

在這台 Mac 上執行，文字不會離開電腦。模型：Kokoro-82M（Apache 2.0）。中文聲音為普通話口音。

  1. 開啟 並登入。API 跟 ChatGPT 訂閱分開計費，Plus／Pro 不含 API 額度。
  2. 按「Create new secret key」，名稱填 Agent Wardrobe，權限選 All（或 Restricted 時開啟語音權限），複製 sk- 開頭的 key。它只會顯示這一次。
  3. 到 確認有餘額。語音按字數或播放時間計費，日常朗讀一句通常不到 1 美分；用量可在 查。
  4. 把 key 貼在下面，按「驗證並儲存」。

保管方式：key 驗證成功後才儲存，加密存在這台 Mac（由 macOS 鑰匙圈保護），不寫進設定檔、之後也不會再顯示，只會送到 api.openai.com。不要把 key 貼到聊天框或分享給別人；懷疑外洩就到 API keys 頁面刪掉舊的、換一把新的。
